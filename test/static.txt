# The tests npm run test:static runs (t512). Each entry names one test file
# and, after it, why it is here. A test belongs when its subject is this
# repository's own files: it reads source, docs, shipped scripts and data,
# generated indexes or checked-in fixtures from disk and asserts on their
# content or their consistency with each other or with what the code renders,
# so a change to one without its counterpart fails here in seconds. A test
# whose subject is runtime behaviour, using fixtures, throwaway repositories
# or a source slice only as data or as code to run, stays in the full suite,
# and so does any test that starts a server, a Durable Object or a network
# call, however fast: test/static.mjs refuses to run a list holding one, and
# test/static-suite.test.mjs reads every entry's imports and calls to keep
# that refusal honest.
#
# PAVI, 2026-11-06: t503, t504 and t505 landed with typecheck alone and broke
# main, every failure in a test of this kind, each under a second, so this
# gate runs that class before a landing. It changes no required check: the
# full suite stays the required one until the orchestrator measures whether
# this list can replace it.
#
# Run at an older revision: a listed file that revision does not hold (added
# later, as t504 added test/criteria-policy.test.mjs) is left out of the copy
# of this list there, and so is test/static-suite.test.mjs, whose pins are
# bound to this tree.
