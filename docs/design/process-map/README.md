# Process map: the approved mockup for t558

PAVI chose this direction (A, process map) on 2026-11-08 from three options. `a-process-map.html` opens in a browser from this folder and links the site's real CSS in `src/`; `dash.css` holds the page's own styles; the PNGs are its renders at 1280 and 390 wide, light and dark. `numbers.json` holds the figures it shows, computed from `atelier flow --json` and `--bars` on 2026-11-08.

Faked in the mockup, to be made real by the build: the 7/30-day switch does nothing; the Ship block estimates merge-to-deploy as the difference of two medians; criteria rejections are shown as not recorded; the "Decisions 3" badge and the owner name in the top bar are placeholders.
