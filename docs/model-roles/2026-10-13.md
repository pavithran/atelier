# Role judgements held on 2026-10-13

These are the judgements of which model does what that the orchestrator
holds on 2026-10-13, written so they can be recorded as role assignments
(t622, `atelier models assign`) once the server carrying `models.roles.v1`
is deployed on 2026-10-16. Nothing here has been applied to any server.

The reasons come from the orchestrator's model assessment
(`~/.claude/skills/atelier-orchestrating/models.md`, entries dated
2026-10-09 to 2026-10-13). Every piece of evidence is a task in this project,
written `atelier/tN` as the command takes it; a bare `tN` would be refused.

## Before recording

- Check each harness/model against the pool with `atelier models`; a choice
  the pool does not have is refused.
- Each `--quote` must be PAVI's own words for that judgement, taken from the
  session where PAVI gave them. None is written here, because none should be
  invented; the placeholder `PAVI_WORDS` marks where they go.
- Run each command with `--as` naming the harness/model recording it for PAVI.
- Nothing stands yet, so no command needs `--replaces`.

## security-review: codex/gpt-6-astra

Reason: the strongest security reviewer on record. On the fast land scan
(t592, t593) Gemini 4 Argon approved while gpt-6-astra found three real
blocking defects in the same diff: merge hooks keeping the developer's
environment, commits made by the test step after the scan, and an
unreadable object without its path. Every finding of its reviews judged

  --evidence atelier/t595 --evidence atelier/t605 --evidence atelier/t604 \

## Frontier tier: fable-5.1, opus-5.5, gpt-6-astra, gemini-4-argon

PAVI set this on 2026-10-13. The tier is not a role assignment: it is the
pool's `tier`, which is informational and read by no selector, so it is set
on each pool entry rather than recorded with `models assign`. Its date and
reason live here and in the orchestrator's decisions.

```text
atelier models set fable-5.1 --tier frontier
atelier models set opus-5.5 --tier frontier
atelier models set gpt-6-astra --tier frontier
atelier models set gemini-4-argon --tier frontier
```

Check the pool's ids first (`atelier models`): `models set` takes the
entry's id, and Opus may be in the pool under more than one harness.
